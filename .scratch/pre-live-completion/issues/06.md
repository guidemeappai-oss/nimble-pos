# PL-06: Zamknięcie dnia

**Zakres źródłowy:** MM-23

**User Story:** Jako kierownik chcę zamknąć dzień z jawnymi wyjątkami, aby móc prowadzić lokal na podstawie spójnych danych.

**What to build:** Zamknąć dzień z jawnymi wyjątkami — kompletny przepływ interfejsu, API i trwałego zapisu, jeśli zadanie obejmuje funkcję.

**Blocked by:** PL-04, PL-05

**Status:** implemented-local — zamknięcie, snapshot, przeniesienia/odstępstwa i historia zintegrowane; testy natywne i pełny odbiór pozostają otwarte.

## Kryteria odbioru

- [ ] Decyzja albo uzasadnione przeniesienie dla otwartych zadań, różnic i zwrotów.
- [ ] Zamknięcie dnia, zmiana kasowa, wylogowanie i czas pracy są odrębne.
- [ ] Późna płatność lub zwrot pozostają obsługiwane; raport zachowuje punkt odcięcia.
- [ ] Test północy, DST, powtórnego zamknięcia i płatności w trakcie zamykania.
