# PL-04: Odbiór utylizacji i wyjątków

**Zakres źródłowy:** MM-21b

**User Story:** Jako kierownik chcę zatwierdzić udokumentowane rozliczenie żywności, aby móc prowadzić lokal na podstawie spójnych danych.

**What to build:** Zatwierdzić udokumentowane rozliczenie żywności — kompletny przepływ interfejsu, API i trwałego zapisu, jeśli zadanie obejmuje funkcję.

**Blocked by:** PL-03

**Status:** implemented-local — przepływ i testy lokalne gotowe; odbiór natywnego PostgreSQL pozostaje otwarty (PL-02). Kontynuacja implementacji zgodnie z poleceniem użytkownika z 2026-10-16.

## Kryteria odbioru

- [ ] Zdjęcia przed/po, powód, opcjonalny świadek i jawne odstępstwo właściciela.
- [ ] Zgłoszona ilość jest wyłączona ze sprzedaży; akceptacja księguje raz.
- [ ] Odrzucenie dokumentacji zniszczonego towaru nie odtwarza zapasu; pozostawia sprawę do wyjaśnienia.
- [ ] Test równoległej sprzedaży, podwójnej akceptacji i utraty odpowiedzi.
