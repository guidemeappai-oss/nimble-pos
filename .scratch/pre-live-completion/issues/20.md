# PL-20: Rozliczenia i eksport

**Zakres źródłowy:** MM-25

**User Story:** Jako właściciel chcę uzgodnić sprzedaż z przepływami, aby móc prowadzić lokal na podstawie spójnych danych.

**What to build:** Uzgodnić sprzedaż z przepływami — kompletny przepływ interfejsu, API i trwałego zapisu, jeśli zadanie obejmuje funkcję.

**Blocked by:** PL-06, PL-08, PL-12

**Status:** implemented-local — odbiór natywny i urządzenie nadal otwarte.

## Kryteria odbioru

- [x] Oddzielnie sprzedaż, wpływy, zwroty wysłane/potwierdzone oraz zobowiązania per aktywo.
- [x] Fiat według historycznej wyceny; rabaty i nadmiarowe wpłaty nie fałszują sprzedaży.
