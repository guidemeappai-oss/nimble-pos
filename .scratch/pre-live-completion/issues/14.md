# PL-14: Receptury i jednostki

**Zakres źródłowy:** MM-14a

**User Story:** Jako właściciel chcę zapisać zużycie składników produktu, aby móc prowadzić lokal na podstawie spójnych danych.

**What to build:** Zapisać zużycie składników produktu — kompletny przepływ interfejsu, API i trwałego zapisu, jeśli zadanie obejmuje funkcję.

**Blocked by:** PL-02

**Status:** implemented-local — wersjonowane receptury, jednostki, snapshoty i rozchód zintegrowane; natywny PostgreSQL i końcowy odbiór nadal otwarte.

## Kryteria odbioru

- [ ] Wersjonowane receptury, jednostki stałej precyzji, dodatki i zamiany.
- [ ] Edytor odrzuca niezgodne jednostki i cykle; podgląd pokazuje zużycie wariantu/zestawu.
- [ ] Ustalić i opisać wycenę: domyślnie średnia ważona; brak kosztu pozostaje brakiem danych.
- [ ] Istniejące gotowe porcje nadal działają bez receptury.
