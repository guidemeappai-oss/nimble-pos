# MM-20: Zdjęcia i odbiór wykonania zadania

**User Story:** Jako pracownik chcę dołączyć zdjęcie wykonanej czynności, aby przekazać dokumentację kierownikowi.

**What to build:** Kompletny przepływ na telefonie, przez publiczne API do trwałego zapisu i ponownego odczytu.

**Blocked by:** MM-19

**Status:** completed — implementacja lokalna i regresja zakończone.

## Kryteria odbioru

- [x] Zdjęcia przed/po według szablonu, podgląd, ponowienie uploadu i jawny status zapisu.
- [x] Prywatny odczyt sprawdza lokal i uprawnienie; serwer wiąże plik z zadaniem, zgłoszeniem i autorem.
- [x] Kierownik akceptuje lub zwraca do poprawy; autor nie akceptuje własnego zgłoszenia; jednoosobowy lokal ma oznaczoną deklarację właściciela.
- [x] Limity, retencja, usuwanie EXIF i czyszczenie po zmianie kasjera; brak automatycznej oceny uczciwości.

## Testy i zakończenie

Testować publiczne zachowanie API z bazą i interakcje telefonu: główny scenariusz, brak uprawnień, izolację lokalu, retry i utratę połączenia tam, gdzie wpływają na wynik. TypeScript, właściwa regresja i code-review przed zakończeniem. Etap daje samodzielnie demonstracyjny rezultat; nowe schematy i interfejsy powstają razem z obsługiwanym przepływem.
