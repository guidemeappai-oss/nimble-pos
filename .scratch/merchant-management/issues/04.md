# MM-04: Wersje menu i edycja zbiorcza

**User Story:** Jako właściciel chcę przygotować menu przed publikacją, aby uniknąć przypadkowych cen podczas sprzedaży.

**What to build:** Kompletny przepływ na telefonie, przez publiczne API do trwałego zapisu i ponownego odczytu.

**Blocked by:** MM-01
