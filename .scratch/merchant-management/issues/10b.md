# MM-10b: Powiązanie menu ze wspólnym zapasem

**User Story:** Jako właściciel chcę powiązać warianty i zestawy z zasobami, aby wszystkie ścieżki sprzedaży korzystały z tych samych ilości.

**Blocked by:** MM-06, MM-10a.

**Status:** implemented-local — powiązania, agregacja i snapshot checkoutu. Wyniki: docs/product/stock-bindings-running.md. Bez wdrożenia.

## Kryteria odbioru

- [x] Właściciel/kierownik konfiguruje powiązanie wariantu i składowych zestawu z istniejącymi zasobami i ilościami.
- [x] Dwa warianty współdzielą zasób bez kopiowania salda; zestaw nie odejmuje tej samej składowej podwójnie.
- [x] Snapshot powiązań jest zamrożony dla checkoutu; zmiana konfiguracji nie zmienia dawnych zakupów.
- [x] Zasób lub opcja bez śledzenia pozostaje obsługiwana; nie naruszamy obietnic lojalności.
- [x] Kontrakt przygotowany do atomowej rezerwacji i rozchodu MM-11, bez fałszywej deklaracji ochrony ostatniej porcji przed jego wdrożeniem.

Po ukończeniu 10a i 10b można zamknąć nadrzędne MM-10. Dopiero MM-11 uruchamia automatyczne zmiany ilości ze sprzedaży.
