# MM-27: Grafik i zastępstwa

**User Story:** Jako kierownik chcę planować obsadę, aby zapewnić pracowników w godzinach otwarcia.

**What to build:** Kompletny przepływ na telefonie, przez publiczne API do trwałego zapisu i ponownego odczytu.

**Blocked by:** MM-01

**Status:** implemented-locally — implementacja i testy lokalne gotowe na `feat/mm27-scheduling`; bez push/deploy. Scalone; bramki natywnego PostgreSQL i urządzenia pozostają otwarte.

## Kryteria odbioru

- [x] Wersjonowany grafik, publikacja, wniosek o zastępstwo i akceptacja.
- [x] Pracownik widzi swój opublikowany plan; konflikty i nieobsadzone godziny są jawne.
- [x] Grafik nie otwiera automatycznie zmiany kasowej.

## Implementacja

- API: drafty i opublikowane wersje grafiku, pobranie planu zalogowanego pracownika, jawne konflikty/niedobory obsady oraz workflow zastępstw z nową wersją grafiku po akceptacji.
- Dostęp: właściciel oraz pracownik z `schedule.manage` zarządzają grafikiem; pracownik widzi wyłącznie swoje zmiany z opublikowanej wersji. Dane są ograniczone do lokalu.
- Czas: każda wersja zawiera jawną strefę IANA lokalu. Telefon nie ustala strefy za lokal; edytor wymaga jej wyboru, pokazuje przed publikacją i wymaga potwierdzenia. Godziny nieistniejące i powtórzone w zmianie DST są blokowane z czytelnym wyjaśnieniem. API odrzuca błędne strefy i lokalne granice tygodnia, które są niejednoznaczne.
- Zmiana kasowa (`merchantShift`) pozostaje niezależna; publikacja grafiku jej nie tworzy ani nie zmienia jej stanu.
- Migracja: `0028_mm27_scheduling.sql`.
- Weryfikacja: `apps/api/test/schedules.test.ts`, `apps/web/test/schedule.test.tsx`; lokalny harness PGlite, TypeScript API/web.

## Testy i zakończenie

Testować publiczne zachowanie API z bazą i interakcje telefonu: główny scenariusz, brak uprawnień, izolację lokalu, retry i utratę połączenia tam, gdzie wpływają na wynik. TypeScript, właściwa regresja i code-review przed zakończeniem. Etap daje samodzielnie demonstracyjny rezultat; nowe schematy i interfejsy powstają razem z obsługiwanym przepływem.
